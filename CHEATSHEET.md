# Tabula · Keyboard cheatsheet

Everything in Tabula has a shortcut. Bring this list up inside the app with **`?`**
(the status bar reminds you). Modifier legend:

> **⌘** = Command (macOS) · **Ctrl** on Windows / Linux. The two are interchangeable
> throughout — pick your platform's one.

## Editing a cell

| Keys                    | Action |
| ----------------------- | ------ |
| `Enter` or `Space`      | Start editing the active cell |
| `Enter` *(while editing)* | Commit & move down |
| `Tab` / `Shift`+`Tab`   | Commit & move right / left |
| `↑` / `↓` *(while editing)* | Commit & move up / down |
| `F2`                    | Jump into the formula bar |
| `Esc`                   | Cancel the edit (revert to the old value) |

## Navigating & selecting

| Keys                    | Action |
| ----------------------- | ------ |
| `↑` `↓` `←` `→`         | Move the active cell |
| `Shift` + `↑↓←→`        | Extend the selection range from the anchor (Google-Sheets style) |
| `Ctrl/⌘` + `A`          | Select the whole grid |
| click a row number / column header | Select that whole row / column |
| drag a selection        | Select any rectangular range |

## Clipboard

| Keys                    | Action |
| ----------------------- | ------ |
| `Ctrl/⌘` + `C`          | Copy the selection (or the active row) to the clipboard |
| `Ctrl/⌘` + `V`          | Paste — a block over the grid, or text into a cell you're editing |

## Editing data

| Keys                        | Action |
| --------------------------- | ------ |
| `Backspace` / `Delete`      | Clear the selected cells (keeps the rows) |
| `Ctrl/⌘` + `D`              | Fill **down** (copy an active value into the rows below) |
| `Ctrl/⌘` + `Shift` + `R`    | Fill **right** (copy an active value into the columns beside) |
| `Ctrl/⌘` + `H`              | Find & Replace (match-case and whole-cell options) |

## Document

| Keys                        | Action |
| --------------------------- | ------ |
| `Ctrl/⌘` + `S`              | Export / save the grid as a `.csv` file |
| `Ctrl/⌘` + `Z`              | Undo |
| `Ctrl/⌘` + `Shift` + `Z`    | Redo |

## Applying formatting

| Keys                        | Action |
| --------------------------- | ------ |
| `Ctrl/⌘` + `B`              | Bold the selection |
| `Ctrl/⌘` + `I`              | Italic the selection |
| `Ctrl/⌘` + `U`              | Underline the selection |
| right-click → **Format**    | Align left / center / right, word-wrap, clear formatting |
| the **Format** button       | Add a conditional-formatting rule to a selection |

## Menus & panels

| Keys                        | Action |
| --------------------------- | ------ |
| right-click a cell / row / column | Open the context menu (categories + items) |
| `←` `→` inside a menu       | Switch the active category |
| `↑` `↓` inside a menu       | Move between items |
| `Enter` in a menu           | Run the item |
| `Esc`                       | Close any open menu, dialog, panel, or selection |
| `?`                         | Show this shortcuts panel (only when not typing in a text field) |

> **Layout & mouse tips** (no keys needed)
> - **Resize** a column by dragging its edge grip; **double-click** the grip to auto-fit.
> - **Reorder** rows or columns by dragging their headers.
> - **Freeze** the top rows with the **Freeze** button (1 / 2 / 3 / 5), or right-click a
>   row → **Freeze rows above**; **Unfreeze** clears it.
> - **Charts**, **Copy as** (Markdown / JSON / SQL), **Auto-filter** and **Sort** are all
>   one click away in the toolbar or the right-click menu.
